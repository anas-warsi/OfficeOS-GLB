Slide 1 Problem Statement

Why a unified workplace system matters

“Many companies use different tools for attendance, tasks, and leave management. This wastes time and creates confusion. OfficeOS solves this by bringing everything together on one platform with role-based access for Admin, Manager, and Employee.”
  • Manual coordination causes delays and poor communication.
  • Data is scattered across multiple tools and departments.
  • Businesses need visibility, accountability, and better workflow control.
Slide 2 Idea & Tech Stack

Simple idea, strong foundation

“OfficeOS is a web-based system. Admin manages employees, managers assign projects and tasks, and employees update their work, attendance, and leave. We built it using HTML, CSS, JavaScript, PHP, MySQL, and Git.”
HTML CSS JavaScript PHP MySQL Git
Slide 3 Architecture

How the system works

“The browser sends requests to the PHP backend. PHP validates the request, checks user roles, interacts with the MySQL database, and returns the dashboard. We use sessions for login security and parameterized queries to prevent SQL injection.”
